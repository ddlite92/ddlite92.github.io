# Dianah Rosli — Portfolio

**Live site:** https://didi.is-a.dev

Personal portfolio for Dianah Rosli, LRC Artist & Pipeline TD with 8+ years in animation production.

## Stack

- Vanilla HTML / CSS / JavaScript — single file (`index.html`)
- Fonts: [Syne](https://fonts.google.com/specimen/Syne), [DM Sans](https://fonts.google.com/specimen/DM+Sans), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) via Google Fonts
- No frameworks, no build step, no dependencies

## Structure

```
index.html          ← entire site (HTML + CSS + JS inline)
images/             ← profile photo
basicProjects/      ← standalone demo apps (calculator, AddToCart, ToDoApp)
favicon.ico
CNAME               ← didi.is-a.dev
_old/               ← archived files from previous version (gitignored)
```

## Sections

| Section    | Description                                               |
|------------|-----------------------------------------------------------|
| Hero       | Display heading, CTAs, stats row                          |
| Work       | Production credits (Animonsta, Warnakala, Digital Durian) + dev tools with terminal previews |
| Experience | Vertical career timeline                                  |
| Toolbox    | Tech stack grouped by category                            |
| Contact    | GitHub, LinkedIn, email                                   |

## Layout

- **Desktop:** fixed left sidebar (220px) + sticky top navbar + scrollable main content
- **Mobile:** sidebar collapses to hamburger menu, top navbar hidden
